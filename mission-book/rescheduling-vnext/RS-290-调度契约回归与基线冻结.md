## 目标
集成 RS-201..203，做动态 provider 池、多设备 scheduler、跨设备回传的完整回归并冻结 presentation-facing contract。

## 施工步骤
1. 从最新 Utopia main 建 integration branch，合入已独立 review 的三个组件分支。
2. 统一重复/冲突状态词，不允许 UI 同时面对三套 availability/busy/handoff vocabulary。
3. 输出稳定 presentation-facing 状态与允许动作，例如：
   - provider 可选/不可选及原因；
   - 是否需要用户 provider choice；
   - queued / running / remote handoff / waiting user / degraded / completed；
   - 可取消/重试/继续等待等动作。
4. 状态必须来自 backend truth，不能专门为 UI 捏造假成功。
5. 运行 concurrency、lease/idempotency、device offline/reconnect、provider flap、real two-device E2E。

7. merge main 后记录 SHA/CI，标记 \`RESCHEDULING_BASELINE_FROZEN\`，解锁 UXI-301。
