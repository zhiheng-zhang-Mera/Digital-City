# SHOW-401 Reports

This directory is populated during execution.

Required before completion:

- `CAPTURE_REPORT.md`
- `REVIEW_REPORT.md`
- `TAKE_SELECTION.md`
- `PRIVACY_QC.md`

The reports must point to the selected media in `../DELIVERABLE_MANIFEST.md`.
No Utopia product-code mutation is permitted by this programme.

## 中文完整说明

此目录在SHOW任务执行期间放置报告；本轮只整理解释文档，不启动SHOW施工。

完成前必须有 CAPTURE_REPORT.md、REVIEW_REPORT.md、TAKE_SELECTION.md、PRIVACY_QC.md。报告须指向 ../DELIVERABLE_MANIFEST.md 中选定媒体。本系列不允许修改Utopia产品代码。
