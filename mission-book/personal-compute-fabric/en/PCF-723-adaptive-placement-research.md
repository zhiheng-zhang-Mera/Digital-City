# PCF-723 — Evidence-gated adaptive placement (optional)

[Canonical state](../PCF-723-adaptive-placement-research.md) · [Shared steps](./EXECUTION_CONTRACT.md). PARKED translation.

Start only after 721 provides baseline data and a specific deterministic-policy limitation. No benefit is a valid result; the word intelligent does not mandate model training. Propose adaptive-policy.mjs and tests, retaining 702's proposal interface.

Select a falsifiable calibration/statistical/lightweight-learning method. Split training/validation/held-out workloads or time periods; do not train and evaluate on the same trace. A safety shield restricts ranking to the policy-feasible set. The learner cannot alter trust, consent, strict targets, review rules or spending authority.

Progress from offline evaluation to shadow decisions, explicitly approved bounded canaries and reversible activation. Version policy/model/input and explain changes. Drift, uncertainty, timeout, out-of-range inputs or excessive overhead fall back to the verified deterministic policy without freezing core or probing privileges.

Acceptance requires invariant tests, held-out experiments, cost/benefit intervals and failures, not training-set average latency. A nondeployment research result must remain labeled as such, not a delivered runtime capability. More complex bandit/RL approaches need separately justified incremental value and safety.
