## Goal

Integrate RS-201..203; fully regress dynamic provider pool, multi-device scheduler and cross-device return, then freeze presentation-facing contract.

## Construction steps

1. Integration branch from latest Utopia main; merge three independently reviewed components.
2. Unify duplicate/conflicting state terms; UI must not face three availability/busy/handoff vocabularies.
3. Stable presentation-facing state/allowed actions: selectable/unselectable provider and reasons; whether user provider choice is needed; queued/running/remote handoff/waiting user/degraded/completed; cancel/retry/continue waiting.
4. State derives from backend truth, never fabricated UI success.
5. Run concurrency, lease/idempotency, device offline/reconnect, provider flap, real two-device E2E.
6. Refresh latest main at that time; rerun full relevant suite and hosted CI.
7. After main merge record SHA/CI, set RESCHEDULING_BASELINE_FROZEN and unlock UXI-301.

## Independent review

Reviewer checks contract stability as a UI consumer and verifies presentation DTO does not feed back into authoritative scheduler state model.

## Completion gates

- RS-201..203 Development+Review complete.
- Unified scheduler vocabulary.
- Real two-device E2E.
- Concurrency/recovery/idempotency green.
- Main merged and main hosted CI green.
- RESCHEDULING_BASELINE_FROZEN.
