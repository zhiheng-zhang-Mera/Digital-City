# Conference Profiles / 会议轨道专项设计

**All entries are design seeds; check exact year/track/stage. / 所有条目均需按年份、轨道和阶段重新核验。**

## 1. ICSE 2027 NIER [S05]

**Observed rules / 已核实:** initial manuscript PDF; IEEEtran 10pt conference format; double-anonymous review; up to four main-content pages plus one references-only page; a Future Plans section. Official cutoff is 2026-10-23 23:59:59 AoE. Open-science and any artifact-stage duties require their own checks. / 不是所有材料阶段都 PDF-only。

**Design specialization / 内部策略:** a clear new idea or emerging result, its relevance, nearest alternatives, initial support and a falsifiable next step. A concept with bounded cases must say it has not undergone effectiveness evaluation. A four-page slice of an incomplete full paper is not automatically a NIER contribution. / 数据少不自动适配 NIER，新意和论证仍需成立。

**Compiler outputs / 输出:** compact question/mechanism/evidence/limitations/future-work outline; references and page-boundary inspection; anonymous PDF and artifact surface review; matching title/abstract metadata; specific claim-permission checks. Preserve the Hns manuscript's own evidence governance; this adapter does not rewrite it.

**Deadline safety / 截止安全:** any portal time inconsistent with the official CFP becomes a conflict requiring clarification. Display a conservative earlier operating warning without rewriting either source. Do not read 12 AM as the end of that day.

## 2. ICSE 2027 Research Track [S14]

**Observed rules / 已核实:** this edition uses IEEE conference format, initial PDF, ten content pages plus two references pages. The full submission deadline was 2026-06-30, so this is a **closed-cycle reference profile as of 2026-10-05**, not an available new submission slot. / 不能把主轨当前列为可立即投递。

**Design specialization / 内部策略:** a complete, independent research contribution with design-appropriate evidence and meaningful comparison where applicable. The factory generates an evidence-gap assessment, not a padded NIER. A later conference year must get a new source-verified profile instead of inheriting these limits.

**Compiler outputs / 输出:** method-specific manuscript and evaluation plan/results distinction; reference-integrity check; complete stage package; anonymous/identity policy and current open-science overlay to be verified. No new main-track deadline is inferred from historical cadence.

## 3. ICSE 2027 Tool Demonstration and Data Showcase [S15]

**Observed rules / 已核实:** four pages including references, IEEE format, single-anonymous review with authors identified. A three-to-five-minute YouTube video is required during review; its URL goes at the abstract's end. Tool submissions link a usable public tool and instructions; dataset submissions link the dataset repository. Artifact evaluation is separate. / 不能复用 NIER 的四页正文加一页参考文献规则，也不能直接上传匿名稿。

**Design specialization / 内部策略:** separate tool and dataset article-type profiles. Tool story: problem -> usable workflow -> selected capability -> boundaries -> access. Dataset story: origin/rights -> sampling/collection -> schema -> quality/limitations -> access. Prefer a reproducible representative use over a tour of every button. / 同轨的工具与数据也不混成同一个写作模板。

**Compiler outputs / 输出:** paper, script/storyboard, real demonstrated workflow evidence, video-link validation, access/install instructions or dataset schema/license, named author metadata and artifact availability map. Do not synthesize successful UI behavior or submit a process monitor as proof of a working application.

## 4. No cross-track shortcuts / 不跨轨套规则

Related tool/data work can coexist with research only when current policies and distinct contribution/overlap checks allow it. Sharing a dataset is not by itself duplicate publication, and changing article type is not by itself a new contribution. Journal-first, artifact evaluation and camera-ready are distinct stages/routes; they are not extra automatic papers. / 具体依据进入论文家族台账。

FSE/ASE or other conferences may be added later only with official edition/track rules and the same source-provenance tests. This design does not invent future CFPs, page limits or dates. / 新增会议先建核实 profile，不从名称猜规则。
