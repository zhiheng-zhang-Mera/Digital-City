## Building role

Planning & Knowledge 像**城市规划院、档案馆和土地储备中心**：它记录未来要造什么、正在推进什么、研究资产如何组织，但不直接冒充运行时代码。

## Roads

- **Planning Road** → all active buildings.
- **Evidence Road** ← project repositories.
- **Promotion Road** → ideas can graduate into dedicated repositories/buildings.

## Boundary

Planning documents do not become runtime truth merely because they describe a future feature. A planned room becomes operational only when an owning repository implements and qualifies it.
