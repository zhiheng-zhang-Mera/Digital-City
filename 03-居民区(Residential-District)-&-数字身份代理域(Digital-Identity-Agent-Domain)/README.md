# Residential — 数字居民与代理建筑

## Direct repository links

- **[Digital-Me](https://github.com/zhiheng-zhang-Mera/Digital-Me)** — 数字居民 / 数字分身能力主体

## Building role

Residential 容纳**具有持续身份、能力边界和行为特征的数字居民/代理**。居民使用城市基础设施，但不是城市本身。

## Buildings and rooms

### [Digital-Me](https://github.com/zhiheng-zhang-Mera/Digital-Me)

**Rooms / capabilities**

- Identity — 数字身份与 profile boundary。
- Skills — 已测量、未验证和可声明能力的区分。
- Real Capability Assessment — 真实任务与 rubric-based assessment。
- Cognitive Profile — 由可观察行为形成的认知特征。
- Persona / Behaviour — 经 Owner calibration 后才可提高相似度声明。
- Voice & Expression — 声音、停顿、用词与表达风格。
- Multilingual Expression — 多语言表达。
- Embodiment — 摄像头、动作、视觉表现等具身接口。
- Interview Agent Surface — 在限定知识和能力边界下代表居民参与交互。

## Roads

- **Identity Road** ↔ Codex-Boss.
- **Capability Road** ↔ city services.
- **Learning Road** → Municipal Learning & Evolution.
- **Privacy Road** ↔ Legal & Privacy.
- **Device Road** ↔ cameras, microphones, wearables and future embodied hardware.

## Boundary

Digital-Me does not become Boss. Boss owns the city substrate; Digital-Me is a resident using that substrate. Persona similarity also must not be inferred from synthetic output alone when Owner calibration is absent.
