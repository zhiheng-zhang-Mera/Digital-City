# 组合能力联合

当已审仓库实现**同一语义的城市能力**时，Digital-City 记录功能／验收**联合**，不选赢家。

```text
城市目标 = 已证明行为(A) ∪ 已证明行为(B) ∪ 后续已审来源
```

规则：保留逐来源溯源；保留有用、不冲突、已验证行为；分开城市全局和领域本地范围；未解决冲突采用更严格安全行为；不强迫立即合并代码；未来抽取必须通过代表全部来源的验收向量。

## 健康领域明确不联合

**Parama 健康状态模型 ≠ Drug Simulator 药理内核。**

二者通过契约集成，不形成联合：
- Parama → 时间一致的生理基线／上下文；
- Drug Simulator → PK／PD／DDI 暴露／机制／终点／不确定性；
- 结果可作为暴露／效应上下文回到 Parama。

不得仅因双方都提及生理／暴露就让一个实现吸收另一个。

## 产品界面明确不联合

- **Utopia 产品外壳 ≠ City Core。** 当前 Web／Android／Gateway 权威是参考实现，可演进而不成为永久宪法权威。
- **City Node Fabric ≠ 08 设备边缘区。** Node Fabric 跟踪已授权运行时／计算存在；08 拥有物理传感器／执行器设备语义。
- **Capability Fabric ≠ 02 Worker Gateway。** Capability Fabric 是全局发现／调用元数据；Worker Gateway 为 Hns 适配工程代理提供方。
- **Room Checklist ≠ City Task。** 清单是用户规划数据；City Task 是运行时执行状态。
- **Room Knowledge ≠ 09 Knowledge Core。** 房间是个人本地内容存储；Knowledge Core 拥有可复用检索／信任／溯源语义。
- **控制中心主题 ≠ 娱乐媒体。** 通用外壳／UI 主题属于 00/05；VR／AR／语音／头像／空间媒体能力留在 11。

## 明确不联合的其他项

Boss 全局调度器 ≠ Hns 工程调度器；Boss City Core ≠ Hns `app/core`；Boss 全局恢复 ≠ Hns 工程恢复 ≠ dsh-restart；City Node 身份 ≠ Hns 资源分析器。相似词汇不足以合并范围。
